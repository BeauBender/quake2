# Function list generator

## About

These shell scripts generate the function lists and
prototypes for saving / loading function pointers
within the savegame system.

## Usage

First generate the data:

```
# cd to stuff/fngen
./fngenprotos.sh ../../src/game > proto.txt
./fngentables.sh ../../src/game > tables.txt
```

Then copy the contents of the files to the respective header
files in the savegame folder.

**NOTE**:: You need to remove `func` and `afterwaitfunc`
from the moveinfo.endfunc lists. This is a side-effect
of how the script identifies points of interest in code.

## Dependencies

These scripts use the following programs / commands:
* dirname
* awk
* grep

Windows users may need to download and install
one or more of these. Tested with Git Bash.

## Implementation details

**fntable.sh** and **fnproto.sh**: Helper scripts that generate
a table and a list of function prototypes for a specified
function pointer.

First `grep` uses function pointer assignments to get a list of
function names, then `awk` removes duplicate names and lastly
`sed` removes `NULL` entries and dresses up the function names
in the table entry/prototype context.

**fngentables.sh**: Writes to stdout the function tables for
all the function pointers in the edict_t struct.

**fngenprotos.sh**: Writes to stdout the prototypes for
all the functions referenced by the tables generated by fngentables.sh.

### Callbacks stored indirectly (moveinfo.endfunc)

The table generator (`fntable.sh`, the `grep` on line 21) only matches a
direct assignment spelled exactly `>moveinfo.endfunc = NAME;`. Functions
passed to `Move_Calc`, `AngleMove_Calc` and `wait_and_change`
(`src/game/g_func.c`) are assigned to `moveinfo.endfunc` inside those
helpers, so the generator never sees them at the call site. Every such
call site must therefore carry a marker comment on the line after the
call, in this form:

```
Move_Calc(self, vec3_origin, door_secret_done);
/* ->moveinfo.endfunc = door_secret_done; */
```

The convention was introduced upstream in commit 948ebb17; see the
existing markers in `g_func.c` near `door_secret_done`.

After adding a marker, regenerate with `./fngentables.sh ../../src/game`,
copy the new `mv_end` block into `gamefunc_list.h` and delete `func` and
`afterwaitfunc` as the NOTE above says.

To check that every indirect callback is in the table, run this from the
repository root. Names on the left (`<`) are callees missing from the
table; names on the right (`>`) are table entries with no such call.
No output means the two sets agree:

```
diff <(grep -ohE '(Move_Calc|AngleMove_Calc|wait_and_change)\([^;]*,\s*[A-Za-z0-9_]+\)' src/game/*.c | grep -oE '[A-Za-z0-9_]+\)$' | tr -d ')' | sort -u) <(sed -n '/fnentries_mv_end/,/^};/p' src/game/savegame/tables/gamefunc_list.h | grep -oE '"[A-Za-z0-9_]+"' | tr -d '"' | sort -u)
```
