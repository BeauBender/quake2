# The groups of the invariants job (TASK211): scripts/ci-checks.sh runs, in
# each job of the matrix in .github/workflows/macos.yml, the checks of
# tests/ci-checks.txt that scripts/ci-select.sh chooses from this map.
# tests/check-ci-map.sh holds the rules; scripts/ci-select.sh has the
# grammar. One entry a line:
#   fast <check>            runs in every fast job
#   ios <check>             runs in every ios job
#   harness <check> <glob>  runs in a pull request's harness job when a
#                           changed path matches <glob>; a harness check
#                           has one line per glob
#   all <glob>              a changed path that matches runs every harness
#                           check (the map itself, tests/ci-checks.txt,
#                           tests/ci-local-only.txt, scripts/ci-checks.sh,
#                           scripts/ci-select.sh and .github/ always do)
#   product <glob>          a path no harness check reads
# A changed path that matches no harness, all or product glob runs every
# harness check. A glob is a case pattern over the whole path: "*" matches
# "/" too, and letter case is ignored. Every check of tests/ci-checks.txt
# is in one group; a check no line names runs in the fast job.
#
# The globs of a harness check are what can change its result: the files it
# reads or runs, found by reading the check. Keep them wide: a missing glob
# lets a pull request skip a check its change breaks, and only the nightly
# run of every check would show it.
