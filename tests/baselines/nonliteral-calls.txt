#   path|callee|first argument|table|reason
# The table names where the names the call walks come from, and the check
# reads its string literals as cvar names (they must be documented): path:Symbol
# is an array (the first literal of each row) or a function (every literal in
# its body) at column 0 of path; fmt:pattern:low:high is pattern with %d from
# low to high, a bound being an integer or a macro (MACRO or MACRO-1) that is
# one plain-integer #define under src. A line without a table or a reason is refused, and so is a line
# whose call is not in src: a walk is listed in the change that adds it.
