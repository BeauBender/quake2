# scripts/pins/rt-variations.txt -- the ray-tracing variation presets and views of
# scripts/rt-variations.sh (TASK173). Each line is one entry, its fields split by "|":
#
#   preset <name> | <caption> | <cvar> <value> [<cvar> <value>]...
#   view   <name> | <base scenario> <demo> <every> | <capture>
#
# A preset is the cvars set on top of a view's base scenario (scripts/pins/scenarios/<base>.cfg);
# "off" sets none, so its frames are the base scenario's own. A view is a base scenario, the demo
# it plays (PINS_DEMO) and its capture cadence (PINS_EVERY), and the capture its contact sheet,
# clip and full-size frames show: a capture number, or "auto:<preset>", the capture in which that
# preset differs most from "off" (the mean difference of scripts/pins/framediff.c). Views of the same
# base, demo and cadence share their records. Names match [a-z0-9][a-z0-9-]*; a caption holds only
# letters, digits, spaces and . , : ; ( ) + - = / _ '; a cvar is an r_rt_* or r_fullbright one,
# a value a number. The presets run in the order of this file.
#
# Every preset that turns on r_rt_ao fixes its noise (r_rt_ao_seed 1), so two runs draw the same
# frames; the records run with PINS_SEED (default 1) for the dynamic lights' radii.
