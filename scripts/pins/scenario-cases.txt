# scripts/pins/scenario-cases.txt -- the cases of the scenario format (FIX122).
# One case a line: "refuse" or "accept", a tab, then one scenario line, kept
# byte for byte (a leading space is part of the case). Lines starting with
# "#" and empty lines are comments. Each case is put after "set timedemo 1"
# in a scenario of its own. The pin harness selftest (scripts/pins.sh,
# st_scenario_lines) records each one, and tests/check-scenario-parsers.sh
# gives each to every reader of the format: scripts/pins.sh, the quake2
# adapter of the bench harness and the MetalFX report generator. A refuse
# case must be refused by each of them, and an accept case accepted.
