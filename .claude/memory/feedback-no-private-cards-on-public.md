The owner requires that this repo's issue board, comments, PRs and committed files (including this memory folder, which is pushed to main) contain quake2 work only. Cards and context belonging to other repos live only in those repos, and nothing here should reveal that such repos exist.

**Why:** This repo is public: anything filed or committed here is published and notified to watchers at once. The owner considered cards from other repos appearing on this board a privacy violation.

**How to apply:** Only quake2 cards on this board. Do not mention other repos' names, card ids, PR or issue numbers, paths or plans in issues, PR text, commit messages or memory notes here; if a fact matters only for another repo, keep it in that repo. The same holds for account details outsiders cannot see, such as which GitHub Apps are installed: record "reviewed by the owner", never the list. The readiness scripts' plugin pin would write the plugin marketplace's repository into `.claude/settings.json`, so never apply it here. See [[feedback-merge-policy]].
