# FIX119: one internal header for ref_metal's backend files (AR-18)

`src/client/refresh/metal/header/rmb_internal.h` (Objective-C only, under `#ifdef __OBJC__`) declares every
function that one `rmb_*.m` file defines and another calls, once. Each defining `.m` includes it and so does
each caller; no `.m` file declares a function by hand. The Makefile builds ref_metal's Objective-C objects with
`-Wmissing-prototypes -Werror=missing-prototypes` (the `REFMETAL_M_WARN` variable, used only by the
`build/*/ref_metal/%.o: %.m` rule, which the iOS, tvOS and visionOS static builds use as well; the C files and
every other target keep their flags), and `tests/check-ref-metal.sh` (section h) refuses a non-static file-scope
prototype in a `metal/*.m` file.

`$(REFMETAL_M_WARN)` stays before `$(CFLAGS)` in that rule, on purpose. A `CFLAGS` or `config.mk` of one's own
can therefore switch the error off (`-Wno-error=missing-prototypes`) for that builder, and the builder keeps
control of their own build. The gate and CI set no `CFLAGS`, so the check holds where it is enforced.
